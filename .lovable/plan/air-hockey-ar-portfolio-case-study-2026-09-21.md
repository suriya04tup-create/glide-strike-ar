# Air Hockey AR Portfolio Case Study

## Goal
Create a single immersive, Behance-style case study that presents the Air Hockey Lens Studio project as a polished game-design and creative-technology piece.

## What I’ll build
- A full-screen air-hockey-inspired opening with strong title treatment, project metadata, and a playable-looking visual centerpiece.
- A long-form editorial story following the requested sequence: context, role, systems, technical insights, iteration, tuning, final result, credits, and reflection.
- Custom visual diagrams for gameplay flow, touch controls, circle collisions, wall boundaries, scoring events, AI targeting, start interaction, and overall architecture.
- Large, clearly labeled editable media placeholders for future gameplay captures, Lens Studio views, and exact Sketchfab credits.
- Transparent authorship language that credits the creator’s work accurately and keeps limited AI assistance secondary.

## Visual direction
- Dark-neutral canvas with crisp off-white typography, electric cyan, signal red, and restrained acid-lime accents.
- Editorial grid, oversized typography, thin technical linework, asymmetric compositions, and generous negative space.
- Air-hockey table geometry, moving puck traces, animated flow lines, subtle parallax, and scroll reveals.
- Full-width visual bands rather than dashboard panels or repetitive card grids.

## Interaction and motion
- Smooth anchor navigation and reading progress.
- Pointer-reactive puck/table visual in the opening.
- Scroll-triggered reveals and restrained parallax with reduced-motion support.
- Animated collision, wall reflection, scoring, and AI-target demonstrations.
- Interactive tuning controls that visually update the gameplay demo without implying a production game.

## Technical notes
- Implement in the existing TanStack Start page and global Tailwind v4 design system.
- Use semantic color and typography tokens throughout.
- Use lightweight React/CSS visuals and Lucide icons; no backend or external data is required.
- Add unique page metadata for sharing and search previews.

## Verification
- Check the complete narrative and all interactions in the live preview.
- Review desktop and mobile screenshots for overlap, clipping, hierarchy, and legibility.
- Confirm all requested attribution placeholders remain editable and no asset creators or links are invented.
